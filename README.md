# Warriors OS Five-Pillar Benchmark — Mobile Login Interface

This public repository hosts only a standalone static HTML login and progress interface. The authenticated API, questions, model calls, saved answers and role checks stay server-side in the Warriors Supabase project.

This is a research-only DeepSeek gateway comparison. It is not a clinical or production WOS decision system. No API secret or private player data is stored here.

The site is hosted through GitHub Pages. Source HTML is intentionally public.
